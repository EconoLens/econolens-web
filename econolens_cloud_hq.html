5 MAKE.COM AUTOMATION FLOWS
The nervous system — every flow runs automatically, every result logged to Notion, every failure alerts CEO
FLOW-01 — NEWS ARTICLE PIPELINE (every 15 min, 24/7)
The core income-generating engine. 30 articles/day. Zero human involvement unless Copyscape score is critical.
01Feedly polls 50+ approved RSS feeds (RBI/IMF/World Bank/Fed/ECB/NBER/PIIE/Brookings/MEA)Feedly
02Source check: must be in approved institution whitelist — reject off-whitelist sourcesMake.com
03Claude API generates 3-layer article with cached system prompt (India context mandatory)Claude API
04aCopyscape scan: score <10% → PASS → Sanity CMS auto-publish with all schema fieldsCopyscape + Sanity
04bScore 10–15% → Claude API regenerates once with different synthesis → re-scanClaude Retry
04cScore >15% after retry → log to Notion Escalation Queue → stop pipeline → alert CCONotion Alert
05Buffer API: LinkedIn + X post (headline + link) within 60 seconds of Sanity publishBuffer
06Beehiiv API: add article to weekly digest queue (parallel with Step 05)Beehiiv
07GA4 Measurement Protocol: track "article_published" event. Write run result to Notion Ops Log.GA4 + Notion
FLOW-02 — SUBSCRIPTION CONVERSION (triggers on user event)
Fully automatic revenue conversion. When a free user hits 5 AI queries, this flow fires and converts them.
01Supabase webhook fires when ai_query_log count reaches 5 for a user_idSupabase
02Clerk API: verify current user plan is still 'free' (prevent double-triggers)Clerk
03Next.js event triggers paywall modal UI → user sees upgrade CTANext.js
04User completes Razorpay (INR) or Stripe (USD) paymentRazorpay / Stripe
05Payment success webhook verified → update subscriptions table (plan='pro', status='active')Supabase webhook
06Clerk API: update user metadata (plan=pro) → unlimited AI access unlocked instantlyClerk + GA4
FLOW-03 — WEEKLY NEWSLETTER (Friday 06:00 IST cron)
AI curates, CEO reviews in 10 minutes, Beehiiv sends. Only human touchpoint in the content pipeline.
01Make.com cron triggers at 06:00 IST every Friday automaticallyMake.com cron
02Sanity API: fetch top 5 articles by GA4 page_views this weekSanity + GA4
03Claude API curates and writes newsletter draft with subject line optionsClaude API
04Cowork saves draft to /content/newsletter/week-[N].md + creates CEO review task in Notion (due 07:00)Claude Cowork + Notion
05CEO reviews and approves in Notion (10 minute budget maximum)CEO approval
06On approval: Beehiiv API sends newsletter + GA4 tracks "newsletter_sent" eventBeehiiv + GA4
FLOW-04 — MONTHLY FINANCIAL CLOSE (last Friday 08:00 IST cron)
Full financial close runs automatically. CEO receives a complete P&L board pack every month.
01Stripe API export: month's subscription revenue, failed payments, refundsStripe
02Razorpay API export: India INR subscription revenue + payment method breakdownRazorpay
03Wave API: reconcile all transactions against recorded entriesWave
04Google Sheets auto-populate P&L template: revenue, COGS, API cost, gross margin, burnSheets + Gemini
05Notion creates "CFO Monthly Review" task for CEO with P&L link attachedNotion → CEO
06Break-even check: subscribers ≥ 29? If not → create gap-to-break-even alert in NotionNotion alert
FLOW-05 — DAILY SITE HEALTH CHECK (08:00 IST cron, daily)
Every system status checked every morning. Any anomaly → Notion alert → COO → CEO.
01Uptime Robot API: get 24h uptime percentage (must be ≥ 99.5%)Uptime Robot
02Sanity API: count articles published today (must be ≥ 28 by 08:00)Sanity
03Buffer API: confirm all yesterday's posts published (0 failed posts)Buffer
04GSC API: check index coverage — flag any new coverage errorsSearch Console
05Write all results to Notion "Daily Site Health: [date]" page under Ops LogNotion
