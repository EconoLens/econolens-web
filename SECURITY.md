# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in EconoLens, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, email: khagankp@gmail.com with subject line `[SECURITY] EconoLens Vulnerability`

We will respond within 48 hours and work with you to resolve the issue.

## Scope

- econolens-web.vercel.app (production)
- econolens.co.in (production domain)

## Out of Scope

- Third-party services (Supabase, Clerk, Sanity, Vercel)
- Social engineering attacks
